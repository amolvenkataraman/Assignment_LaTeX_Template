# Assignment LaTeX template

This is the template I personally use for all my (math) assignments at UWaterloo. Includes imports for all the popular Math libraries, shortcuts for commonly used (and annoying ty type) symbols, and modified page structure to allow more content per page than the default.

Created and improved from 2023 onwards, based on provided templates for various courses. Credits go to respective professors. This template should (hopefully) be allowed by basically every course to submit assignments with, except for a few courses that may require a specific template. Please verify with a professor. I am not responsible for any issues that may occur from the use of this template.

## How to use:
- Create a `.tex` file and paste the template into it.
- Find all the lines with `CHANGEME` and update the relevant content.
- Add your content (answers) to the section of the document labeled by `Document contents go here`
- Enjoy!
